02메뉴 버튼

네 개 모두 씬에 있고 onClick도 TitleScene의 핸들러에 연결돼 있다. 다만 핸들러 본문이 전부 비어 있다 — 눌러도 아무 일도 일어나지 않는다.

버튼표시(Kr)핸들러눌렀을 때

라벨은 StringTable.csv의 키(TitlePlay, TitleHouseSelect, TitleUpgrade, TitleSetting)로 채운다. 한/영/중/일 4개 열이 이미 들어 있고, 언어는 Application.systemLanguage로 자동 판별한다.

04정해야 할 것

구현을 이어가려면 먼저 답이 필요한 항목들이다. 각 선택지의 첫 줄이 지금 구조에서 가장 손이 적게 가는 쪽이다.

현재 종족을 어디에 저장하나?

배경·유닛·인게임이 모두 이 값을 읽는다. 지금은 저장소 자체가 없다.

  • PlayerPrefs에 종족 Id 하나 — 세이브 시스템이 생기기 전까지의 최소 구성
  • 세이브 데이터 클래스를 지금 만들고 그 안에 넣기
유닛 4개를 언제, 어떻게 뽑나?

지금은 에디터에서 한 번 뽑아 씬에 굳어 있다. 종족마다 종류 수가 6~13으로 달라서 중복 규칙도 정해야 한다.

  • 타이틀 진입 때마다 중복 없이 4개 — 매번 달라 보여 화면이 심심하지 않다
  • 고정 4개(대표 유닛) — 종족 정체성이 일관되게 읽힌다
  • 중복 허용 랜덤 — 릴에서 실제로 나오는 분포와 가깝다
종족 선택은 어떤 화면인가?

타이틀 위 팝업인지, 별도 씬인지에 따라 배경 교체 타이밍이 달라진다.

  • 타이틀 위 팝업 — 고르는 즉시 뒤 배경이 바뀌어 미리보기가 된다
  • 별도 씬 — 종족별 규칙 설명까지 넣을 공간이 생긴다
해금 상태를 타이틀에서 보여주나?

GDD상 종족은 체스 → 장기 → 화투 → 포커 순으로 해금된다(풀 크기 순 = 난이도 순).

  • 안 보여준다 — 종족 선택 화면에서만 잠금 표시
  • 타이틀에 진행도 표시 — 다음 목표가 계속 보인다

05알려진 미결 사항

기획이 아니라 구현 쪽 부채

부팅 진입점이 없다. TableManager.init()을 부르는 곳이 없어서, 임시로 TitleScene.OnSetup()에서 호출하고 있다. GameManager 같은 진입점을 만들면 그쪽으로 옮겨야 한다.

BGM이 없다. SoundTable.csv에 TitleTheme 행과 오디오 파일이 모두 없어, 진입할 때마다 조회 실패 로그만 남는다(동작에는 지장 없음).

유닛 스프라이트가 Bilinear + PPU 100이다. GDD 기준은 Point + PPU 32다. ×3으로 확대해 쓰는 지금 구성에서는 도트가 뭉개져 보인다.

배경 배율이 비정수(3.75배)다. 1920×1080에 640×288을 정수 배율로 꽉 채우는 조합이 없다. 정수를 고집하면 위아래가 잘리고, 지금처럼 두면 픽셀 크기가 3px/4px로 불균일해진다.
