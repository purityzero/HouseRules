윷 종족 기획

2. 종족 정체성

한 줄 설명

낮은 실패율로 꾸준히 전진하지만, 같은 도착점을 맞춰 업기를 만들고 희귀한 역행 조합으로 빽도 전용 유닛을 부르는 종족.

  • 판정 문법: 동일성이나 족보가 아니라 부호가 있는 수의 합과 도착점 중복을 읽는다.
  • 플레이 감각: 개별 심볼보다 세 칸의 조합 순서, 합계, 업기 가능성을 본다.
  • 시각 방향: 장기의 왕조·성곽과 겹치지 않도록 민속 마을, 흙길, 장터, 잔치의 분위기를 사용한다. 색상과 시대 고증은 미정이다.
  • 핵심 차별점: 빽도는 단순 실패 심볼이 아니라 음수 조절기이자 전용 유닛의 열쇠다.

4. 판정 규칙

4.1 기본 판정

각 가로줄 [A, B, C] → 세 심볼을 이동값으로 변환 → Landing = A + B + C → Landing > 0 : 일반 소환 → Landing = 0 : 빽도 전용 유닛 소환 → Landing < 0 : 해당 줄 소환 실패

세 가로줄은 각각 독립된 말 한 개로 취급한다. 결과 순서는 합계에는 영향을 주지 않지만 일반 유닛 종류를 고르는 제안 규칙에는 영향을 준다.

4.2 일반 유닛 선택 제안

가로줄을 오른쪽에서 왼쪽으로 훑어 처음 만나는 빽도가 아닌 심볼을 그 줄의 소환 유닛으로 삼는다. 예: [모, 빽도, 개]는 합 6에 도착하고 개 유닛을 소환한다. 이 규칙은 마지막 윷 결과가 말의 형태를 정한다는 직관을 주며, 빽도를 독립 일반 유닛으로 과다 소환하지 않는다.

4.3 빽도 전용 유닛 존재 확정

Landing == 0이면 일반 선택 규칙을 무시하고 빽도 전용 유닛을 소환한다. 균등 6종 풀에서 가능한 조합은 빽도 + 빽도 + 개의 순열 세 가지뿐이다.

전용 유닛의 전투 효과는 미정. 현재 후보는 “소환된 배치 단계의 무료 스왑 +1”이다. 역행을 재배치 기회로 바꾸며 기존 무료 스왑 시스템을 재사용하지만, 사용자 승인 전에는 확정하지 않는다.

4.4 업기 제안

같은 스핀에서 양수 도착점이 같은 줄들은 한 위치에 업힌다. 최소 구현은 유닛을 모두 유지하되 같은 칸의 업기 표시와 업기 보너스를 부여하는 방식이다. 보너스 수치 및 전투 중 분리 규칙은 미정이다. 0이 여러 번 나온 경우 빽도 전용 유닛도 업을 수 있는지는 별도 승인 항목이다.

4.5 잡기와 외부 심볼

  • 잡기: 적 말의 이전 위치 상태가 필요한 규칙이다. 현재의 스핀 단발 판정에는 넣지 않고, 향후 침공과 연결된 영속 윷판 레이어로 보류한다.
  • 전리품 심볼: 기존 GDD 계약대로 이질 심볼이 하나라도 포함된 가로줄은 윷 주판정에서 제외한다. 이질 심볼은 공통 부판정인 짝 판정으로 처리한다.

실제 계수는 일반 유닛 선택과 배치 좌표를 확정한 뒤 몬테카를로 시뮬레이션으로 역산한다. 현재 수치를 임의로 HouseTable 축에 넣지 않는다.

6. 트리거 흐름

  1. 스핀 종료 후 3×3 결과를 확정한다.
  2. 각 가로줄에 이질 심볼이 있는지 검사한다. 있으면 윷 주판정을 건너뛴다.
  3. 순혈 가로줄의 이동값 합을 계산한다.
  4. 음수·0·양수 분기로 실패, 빽도 전용, 일반 소환을 결정한다.
  5. 세 줄의 도착점을 비교해 업기를 판정한다.
  6. 윷·모 연속 진행 보너스를 적용한다(규칙 승인 후).
  7. 소환 결과를 전장 좌표로 변환하고 배치 단계로 넘긴다.
  8. 이질 심볼은 공통 짝 부판정으로 별도 계산한다.

8. 구현 전 승인해야 할 사항

최우선 — 전장 좌표 충돌

기존 GDD는 릴 9칸과 전장 9칸을 1:1로 연결하지만 윷은 가로줄 하나에서 유닛 하나를 만든다. 후보는 ① 줄의 오른쪽 칸, ② 줄의 가운데 칸, ③ 도착값을 3×3 좌표로 환산, ④ 세 심볼 유닛을 모두 놓고 대표 유닛에만 판정 보너스 적용이다. 종족의 실제 플레이를 크게 바꾸므로 승인 없이 선택하지 않는다.

  1. 일반 유닛을 “오른쪽부터 마지막 비빽도”로 정할 것인가?
  2. 윷·모를 실제 추가 스핀 대신 전력/연속 이동 보너스로 표현할 것인가?
  3. 빽도 전용 유닛 효과를 무료 스왑 +1로 할 것인가?
  4. 업기 보너스와 0 결과끼리의 업기 허용 여부는 무엇인가?
  5. 해금 순서, 종족 색, 능력치 축, 아트 시대상은 무엇인가?
  6. 잡기를 향후 영속 윷판으로 확장할 것인가?
