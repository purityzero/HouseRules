[위임 브리프] 마작 5번째 종족 검토 — design-planner에게 넘길 것#

이 파일은 작업 지시서다. 새 세션에서 design-planner 에이전트에게 아래 내용을 그대로 프롬프트로 넘기면 된다. 위임이 끝나고 mahjong-house.md가 나오면 이 파일은 지운다.

(2026-08-25 작성. 위임하려던 세션에서 커스텀 에이전트가 목록에 안 잡혀 넘기지 못했다.)

HouseRulez 프로젝트(절대경로: D:\Unity\HouseRules\HouseRulez)의 기획 검토 건이다.

요청#

사용자가 마작을 5번째 종족으로 추가하고 싶어 한다. 이것이 이 게임의 설계 축을 깨지 않고 가능한지 검토하고, 가능하다면 구현 가능한 스펙으로 정리해달라.

반드시 먼저 읽을 것#

  1. Assets\Design\reel_of_four_houses_GDD.html — 게임 전체 GDD(972줄). 특히:
    • 네 종족의 판정 구조(체스=정렬 / 장기=포 넘기 / 포커=족보 / 화투=섯다)와 각 종족의 심볼 풀 크기, 평균전력·분산·상한·학습비용 축
    • "네 종족의 원본 규칙이 이미 서로 다른 확률 구조를 갖고 있다 — 판정의 종류가 다르지 스킨이 다른 게 아니다"라는 핵심 설계 원리
    • 해금 순서 규칙(풀 크기 순 = 체스6 → 장기7 → 화투12 → 포커13, "심볼 수가 곧 난이도 지표")
    • 아트 파트의 종족 액센트 색과 "검정은 적군 전용, 환경 최암부 #363B4A" 절대 규칙
    • 11장 데이터 테이블 스키마(House.csv, Symbol.csv 등)
  2. Assets\Design\title_screen_design.html — 타이틀 화면 설계(현재 구현 상태와 미정 항목)

검토해야 할 핵심 쟁점#

  • 판정 종류의 중복: 마작의 슌쯔(연속 3장)는 포커의 스트레이트와, 커쯔(같은 3장)는 포커의 트리플/체스의 정렬과 겹친다. 기존 넷은 전부 라인(가로3·세로3·대각2) 또는 열 단위로 읽는다. 마작이 별개 종족이 되려면 어떤 판정 축을 가져와야 하는가. 한 가지 후보: 라인을 아예 안 보고 9칸 전체를 3장씩 세 묶음으로 분할(전역 조합 최적화) — 9칸의 3분할은 280가지라 완전탐색 가능. 이 축이 타당한지, 더 나은 축이 있는지 판단해달라.
  • 심볼 풀 크기: 마작 전체는 34종(수패 27 + 자패 7)이라 포커 13보다 훨씬 크다. GDD가 포커 13종조차 초심자 이탈 위험으로 지적했다. 수패 한 종류만 써서 1~9의 9종으로 줄이는 안이 타당한가.
  • 해금 순서 규칙 충돌: 풀 9종이면 장기(7)와 화투(12) 사이인데, 학습 비용은 마작이 가장 높을 가능성이 크다. "풀 크기 순"이라는 기존 규칙을 유지할지 바꿀지.
  • 밸런스 축: 기존 넷의 평균 전력 6163, 변동계수 0.641.73 범위 안에서 마작을 어디에 놓을지. 기존 넷과 차별되는 정체성 한 줄.
  • 문화권 중복: 현재 장기 배경이 "한국·중국 고대"로 잡혀 있어 마작(중국)과 겹친다. 배경 테마 분리안이 필요하다.
  • 액센트 색: 체스 #7FA7C9 / 장기 #57A277 / 포커 #D6A441 / 화투 #D1554C가 이미 쓰였다. 남는 색 제안(청록·보라 계열 등). 반드시 환경 최암부 한계 #363B4A(휘도 L59.2)보다 밝을 것.

산출물#

.claude\design\mahjong-house.html 에 구현 가능한 스펙으로 정리할 것. 포함할 것:

  • 결론(가능 / 불가 / 조건부 가능)과 그 근거
  • 판정 규칙의 정확한 정의와 점수 구조(기존 종족의 점수 스케일과 직접 비교 가능하게)
  • 심볼 풀 정의(무엇을 몇 종 쓰는지, CSV 스키마 관점)
  • 기존 테이블/코드와의 접점
  • 엣지 케이스와 미해결 결정 항목
  • 배경/색 테마 제안

코드와 테이블은 직접 수정하지 말고 스펙 문서만 작성해라. 판단이 서지 않는 지점은 임의로 결정하지 말고 선택지와 트레이드오프를 적어 남겨라.
