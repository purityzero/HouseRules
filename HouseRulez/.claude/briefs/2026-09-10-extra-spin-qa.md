같은 화면에서 직전 세션이 80턴을 소진한 전례가 있다(런을 여러 번 돌려서). **런 1회면 충분하다.**

## 무엇이 바뀌었나

GDD 03장 **"추가 스핀 골드 25 → +1, 연차당 2회까지, 가격 고정"**을 구현했다.

배경: 「패배하면 같은 웨이브를 다시 한다」(Q3-B) 규칙이라 재도전에 스핀이 필요한데,
기본 코인 3개는 웨이브 3개와 1:1이라 여유가 0이었다. **그 여유를 골드로 사는 것이 GDD 설계다.**
(어제 임시로 `SpinCoinPerYear`를 5로 올려뒀던 것을 3으로 되돌렸다.)

| 파일 | 변경 |
|---|---|
| `GameConfigTable.csv` | `SpinCoinPerYear` 5 → **3** 원복, `ExtraSpinGoldCost`=25 · `ExtraSpinMaxPerYear`=2 신규 |
| `RunData` | `IsExtraSpinBuyable()` · `BuyExtraSpin()` 신설, 연차 전환 시 **구매 횟수도 리셋** |
| `InGameScene` | 구매 핸들러. **런 종료 조건 변경** — 코인 0이어도 살 수 있으면 안 끝난다 |
| `UIInGameAction` | 버튼·라벨·이벤트, 남은 횟수 표시, 못 살 때 `interactable=false` |
| `StringTable.csv` | `ActionExtraSpin` = `추가 스핀 {0}G ({1}회)` |
| `InGameScene.unity` | ACTION 영역에 `ExtraSpinButton` 추가(위치는 직전 작업에서 조정됨) |

## 검증 항목 — 요구마다 1:1로 단언

1. **기본 코인이 CSV대로 3인가**
   ⚠️ **화면 값이 3이 아닐 수 있다.** `RunData.Init()`이 메타 업그레이드 보너스
   (`PlayerManager.GetRunConfigBonus`)를 더하기 때문이다. 직전 QA에서 이 때문에 8이 나왔다.
   → **`GameConfigTable`의 `SpinCoinPerYear` 원본값이 3인지**와
   **`spinCoinMax` = 3 + 보너스**가 맞는지 두 개를 각각 확인하라. 화면 숫자만 보고 판정하지 말 것.
2. **추가 스핀 구매가 실제로 되는가** — ACTION 영역의 추가 스핀 버튼을 **실제 클릭**해서
   ①골드가 **정확히 25** 줄고 ②스핀 코인이 **정확히 1** 늘고 ③버튼 라벨의 남은 횟수가 1 줄어드는지.
   골드는 스핀 시 판정 전력에 비례해 들어오므로, 25가 모일 때까지 몇 번 스핀하면 된다.
3. **연차당 2회 제한이 걸리는가 (부정 경로)** — 2회 산 뒤 **3회째가 막히는지**.
   버튼이 `interactable=false`가 되고, 그 상태로 눌러도 **골드가 안 줄어드는지** 계수로 단언하라.
4. **골드가 모자라면 못 사는가 (부정 경로)** — 골드 < 25일 때 버튼이 비활성인지,
   눌러도 코인이 안 늘어나는지.
5. **연차가 넘어가면 구매 횟수가 리셋되는가** — 1연차에서 2회 다 쓰고 2연차 진입 후
   **다시 살 수 있게 되는지**(버튼 재활성).
6. **런 종료 조건이 구매 가능성을 반영하는가 (이번 변경의 핵심)**
   코인이 0이 된 시점에 **골드가 25 이상이고 구매 횟수가 남아 있으면 런이 끝나면 안 된다.**
   반대로 **코인 0 + (골드 부족 또는 횟수 소진)**이면 런 종료 팝업(`스핀 코인 소진`)이 떠야 한다.
   둘 중 도달 가능한 쪽을 확인하고, 못 만든 쪽은 이유를 적어라.
7. **라벨이 실제 값으로 뜨는가** — `ActionExtraSpin`이 키 문자열 그대로 뜨지 않는지,
   `{0}`·`{1}`이 남아 있지 않은지. **4개 언어를 순회**해 `□`가 없는지도 확인하라.
8. **콘솔 에러 0건** (기존 `CS1998` 경고와 EventSystem 2개 경고는 제외).

## 지켜야 할 것
- **프로덕션 경로.** `BuyExtraSpin()`·`OnBuyExtraSpin()`을 코드로 직접 부르지 말고
  화면 버튼을 EventSystem 경유로 실제 클릭한다.
- **상태 플래그가 아니라 화면·데이터에 실제로 들어간 값**을 읽어라.
- **프로젝트 파일 수정 금지.** 산출물은 `Temp/` 아래에만. 결함은 고치지 말고 보고만.
- 끝나면 Play Mode 종료.
