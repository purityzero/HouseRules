## 검증 항목 — 요구마다 1:1로 단언

1. **유령 승리 회귀 없음** — 인게임 진입 후 무입력 3초. 웨이브가 안 오르고 배너·팝업이 안 뜨는가.
   초기 스핀 코인이 **5**인지도 확인(설정 반영 여부).
2. **패배 시 웨이브가 유지되는가** — 일부러 약한 판으로 져 본다.
   ①`waveIndex`가 그대로인가 ②본거지 HP가 `leak×1 + 1`만큼 줄었는가
   ③재도전하려면 스핀이 필요하고 그 스핀에 코인이 **1** 드는가
3. **연차 전환 시 코인이 회복되는가 (기존 결함 D4의 해소)** — 1연차 3웨이브를 이겨 2연차 진입.
   ①`year`가 2, `waveIndex`가 1인가 ②**스핀 코인이 5로 되돌아왔는가**
   ③연차 시작 배너가 `{0}`이 아니라 실제 숫자로 뜨는가(포맷 인자 확인)
4. **런이 실제로 닫히는가** — 아래 둘 중 **도달 가능한 쪽 하나 이상**을 확인하면 된다.
   ①본거지 HP를 0까지 떨어뜨림 → 팝업 제목이 `본거지 함락`
   ②코인을 다 소진 → 팝업 제목이 `스핀 코인 소진`
   공통 확인: **팝업이 화면에 실제로 보이는가**(도달 연차·옥새 숫자가 키 문자열이 아닌 실제 값으로),
   팝업이 뜬 뒤 **SPIN·BATTLE이 안 눌리는가**, `타이틀로` 버튼으로 타이틀 씬에 도달하는가.
5. **옥새가 실제로 늘었는가** — 타이틀로 나간 뒤 업그레이드 화면의 **옥새 숫자가 증가**했는지.
   상태 플래그가 아니라 **화면에 들어간 값**을 읽어라. 종료 사유별로 `EndRun`이 두 번 불려
   이중 지급되지 않는지도(멱등 가드) 확인.
6. **콘솔 에러 0건** — 기존 `CS1998` 경고와 EventSystem 2개 경고는 제외.
